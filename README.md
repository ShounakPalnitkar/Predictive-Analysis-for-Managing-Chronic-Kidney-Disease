This project compares traditional ML models (e.g., Random Forest, SVM, Logistic Regression) with Large Language Models (LLMs) to assess their strengths on structured and unstructured data. Based on the analysis, I developed a hybrid system where ML handles backend predictions, while an LLM (e.g., GPT) powers the chatbot's conversational interface. The resulting chatbot delivers intelligent, context-aware responses by combining data-driven predictions with natural language understanding, enhancing both accuracy and user experience.
